# Журнал разработки

## Исходное состояние

В репозитории были выбраны Казань и вторичный рынок жилья. Три коммита содержали формулировку темы, настройки FastAPI и `/healthz`, асинхронное подключение и таблицы недвижимости. Пять тестов проверяли конфигурацию, БД и healthcheck.

## 26 ноября 2026

- Уточнены два прикладных сценария. Оценка квартиры использует табличную историю, прогноз рыночного ряда принимает отдельный CSV.
- Реализованы доменные модели, Pydantic State, артефакты по ссылкам, Supervisor и агенты. Добавлены три инструмента для каждого сценария.
- Настроены DeepSeek, Ollama и OpenAI-совместимый транспорт. Валидируются имя и схема инструмента. Проверки с моками покрывают нативный вызов, ошибки HTTP, некорректные параметры и резервный выбор.
- Созданы генерация и импорт 1168 кейсов и 500 записей справочника. Подключены BM25, PCA, RRF и адаптер Qdrant.
- Добавлены авторизация, очередь прогнозов и оценки, сохранение результатов, дерево событий, логи LLM, кэш и история решений HITL.
- Подготовлены интерфейс прогноза, история, очередь проверки и экран сравнения режимов.
- Подключены локальный запуск, Docker Compose и проверки CI. Проверка Compose на синтаксис пройдена.
- Выполнены локальные оценки по нескольким горизонтам и долям истории. Методика и ссылки на результаты приведены в [отчёте](REPORT.md).

## Границы проверки

Сквозные тесты локального API выполнялись через FastAPI TestClient и SQLite. В рабочей среде установка пакетов из сети, привязка сетевого порта, внешний вызов DeepSeek и подключение к Docker daemon были недоступны. Реальный ключ в файлы проекта не записан. Для проверки действующего ключа есть отдельная команда в [инструкции запуска](DEPLOYMENT.md).

В основном прогоне Python 3.12 прошли 17 тестов, два были пропущены из-за отсутствия SciPy и statsmodels в этом окружении. Покрытие backend составило 85%. Отдельный прогон на Python 3.11 с SciPy 1.15.2 и statsmodels 0.14.4 проверил все четыре теста статистической обработки.

## 27 ноября 2026

- Добавлен раздел «Настройки» с провайдером, моделью, сохранением API-ключа для аккаунта, проверкой нативного вызова и возвратом конфигурации сервера.
- Интерфейс переведён на простой набор текстовых элементов, полей и разделительных линий. Проверены раскладки Chrome при ширине 320, 390 и 1440 пикселей.
- Сквозная проверка в браузере прошла от регистрации до прогнозов квартиры и CSV, просмотра истории и трассировки, выгрузки результата и запуска эксперимента.
- Выполнена чистая установка через `scripts/bootstrap.sh`. Все 28 тестов прошли с покрытием backend 84,34%. Живой DeepSeek успешно выполнил проверку подключения и полный агентный прогноз с ключом тестового профиля. Ключ удалён из этого профиля после проверки.
- Повторная оценка на 20 рядах с включённой статистической диагностикой вернула 720 результатов без пропущенных запусков.
- Практический запуск Docker Compose прошёл. Через Nginx проверены сохранение профиля в PostgreSQL, прогноз и пакетная оценка через Celery/Redis, поиск в Qdrant и обмен с HITL. Контейнер Ollama запущен отдельно. Вызов локальной модели проверен на транспортном моке.
- Перезапущен локальный REPF на порту 8000. Проверены healthcheck и наличие новых маршрутов в OpenAPI.

### Именованные пресеты и инструкции команды

- Добавлены несколько пресетов на аккаунт, выбор активной модели, повторная проверка и удаление. При сохранении и переключении проверяется реальный нативный вызов инструмента. Прежний одиночный профиль остаётся доступен в списке.
- В Chrome проверено, что DeepSeek отклоняет выдуманный идентификатор до сохранения. Рабочий DeepSeek-пресет и локальный пресет сохраняются независимо. Проверены переключение, повторный пробный вызов, обновление страницы, возврат к настройкам сервера и удаление.
- Прошли 30 тестов. Покрытие backend составило 84,35%. В Docker проверены сохранение двух пресетов и выбор в PostgreSQL, запуск прогноза через Celery и удаление активного пресета.
- В README добавлены реальные скриншоты окон прогноза и настроек. Обновлены инструкции для macOS, Linux и Windows, описания API, архитектуры, данных и повторения оценки. Для Windows x64 проверено разрешение зависимостей Python 3.12 через pip dry run. Запуск на Windows не выполнялся.
