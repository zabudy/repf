### Казань

В `kazan_secondary_quarterly.csv` собрана средняя цена квадратного метра на вторичном рынке Казани в рублях. Значения взяты из листа «по центру субъекта РФ» по строке Татарстана и графе «Все типы квартир». В CSV дата обозначает начало наблюдаемого квартала. Значения за 2021 год — II квартал 2026 сверены с таблицами Росстата в архиве RPGI. Значение за III квартал 2026, 188 788,45 ₽/м², взято из копии выпуска Росстата от 30 октября 2026 года. [Росстат](https://rosstat.gov.ru/folder/13397), [архив RPGI](https://doi.org/10.5281/zenodo.24115487), [копия выпуска за III квартал](https://roschart.ru/dataset/sred-cen-vtor-3kv-2026-srednie-ceny-na-vtorichnom-rynke-zhil-2).

Локальная выгрузка `data/raw/kazan_rosreestr_apartment_sales.csv` содержит 8 837 строк из открытого набора Росреестра за I квартал 2025 — II квартал 2026. Условия отбора — Казань и кадастровый префикс `16:50:`, договор купли-продажи жилого помещения (коды `002001003000` и `206002000000`), валюта рубль, `number = 1`, положительные цена и площадь. В выгрузке сохранены квартал, площадь, цена, рассчитанная цена за м², этаж, год постройки и код материала стен. Пропуски, выбросы и возможные дубли сохранены. Договор купли-продажи сам по себе не определяет сегмент рынка. В исходных полях для этой выборки отсутствуют точные даты сделок, административный район и этажность дома, необходимые для загрузки во вкладке «Квартира». [Зеркало открытого набора Росреестра](https://github.com/g-turkin/rosreestr-deals).

## Загрузка временного ряда

CSV в UTF-8, заголовки `date,value`, даты формата ISO. Поддерживаются разделители запятая, точка с запятой и табуляция. Нужно минимум 12 наблюдаемых периодов. Частоты `D`, `W`, `MS`, `QS`. Пустые периоды внутри ряда заполняются предыдущим наблюдением, дубликаты в одной временной корзине усредняются. Ряды с более чем половиной пропусков отклоняются.

## История квартир

В UI «История рынка JSON» принимает массив записей или объект с полями `market` и `market_index`. После загрузки список районов или городов берётся из поля `district`. Обязательны `date`, `price_rub`, `area_total` и `district`. Этаж, этажность, год постройки, тип дома и состояние можно опустить, если их нет в источнике. Ниже приведена одна строка истории.

```json
{
  "date": "2024-01-15",
  "district": "Советский",
  "area_total": 53.5,
  "floor": 4,
  "floors_total": 9,
  "build_year": 1989,
  "house_type": "panel",
  "condition": "cosmetic",
  "price_rub": 6050000
}
```

Передайте минимум 40 строк, распределённых по месяцам. Нужно достаточно истории для формирования месячного индекса и разбиения на ранние и поздние месяцы. Оценка падает с понятным сообщением, если данных недостаточно. При наличии внешнего положительного месячного индекса он должен покрывать все месяцы истории продаж. По умолчанию индекс строится как месячная медиана цены за м².

### Файлы для демонстрации

Готовые JSON лежат локально в `data/raw/`. Откройте «Квартира», загрузите один файл в поле «История рынка JSON», выберите район или город и введите площадь. Для американских примеров оставьте этаж и этажность пустыми. Тип дома и состояние можно выбрать как «Не указан» и «Не указано». Для демонстрации можно выбрать горизонт 3 месяца и режим «Базовый».

## База знаний и справочник

```bash
.venv/bin/python -m scripts.generate_knowledge_base
.venv/bin/python -m scripts.import_data
```

В PowerShell используйте интерпретатор Windows-окружения.

```powershell
.\.venv\Scripts\python.exe -m scripts.generate_knowledge_base
.\.venv\Scripts\python.exe -m scripts.import_data
```

Для каждого временного кейса шесть конфигураций сравниваются на правом отложенном окне. В корпус сохраняются признаки предшествующей истории, выигравшая модель, аргументы и метрики. Для квартир конфигурации сравниваются на поздних месяцах каждого синтетического рынка. Справочник содержит 25 понятий, описанных в 20 прикладных контекстах, всего 500 поисковых записей.

Артефакты записываются в `data/processed/`. Повторный импорт обновляет существующие идентификаторы. Он также публикует векторный индекс при настроенном `QDRANT_URL`.
