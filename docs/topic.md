# Формулировка темы

**Тема:** Мультиагентная система прогнозирования цен на недвижимость (вторичный рынок жилья, г. Казань) с проверкой данных, ансамблем моделей и объяснением факторов.

1. **Что делает система?** Оценивает стоимость квартиры и прогнозирует динамику цен на 1–12 месяцев, проверяя результат независимыми агентами.
2. **Для кого?** Аналитик / оценщик залога; частный покупатель или инвестор.
3. **Вход и выход?** Вход — параметры объекта (район, площадь, этаж, этажность, год постройки, тип дома, состояние) и горизонт прогноза.
   Выход — цена (точка + 80 % интервал), уверенность 0–1, топ-5 факторов (SHAP), текстовое пояснение, флаг «нужна проверка экспертом».

## Границы (чтобы тему можно было защитить)
- Только жилая недвижимость, вторичный рынок, один город.
- Не заменяет официальную оценку; это поддержка принятия решения.
- Валидация по времени, а не случайным разбиением.

## Агенты
Collector, Validator, Forecaster, Critic, Explainer, Supervisor (при работе в одиночку — Validator, Forecaster, Critic).
